# 金陵有迹 · 南京城市文化交互地图

一座城，半部历史。在这里，遇见南京的过去与现在。

一个以南京城市文化为主题的交互式网页原型（大学生设计竞赛 · 数字媒体设计方向）。

---

## 目录结构

```
jinling-youji/
├── index.html          # 首页（唯一页面，单页应用）
├── css/
│   ├── base.css        # 设计变量（配色/字体/间距）、重置、通用排版
│   └── layout.css      # 导航、Hero、Section、页脚的布局
├── js/                 # （阶段②起使用：数据、地图、交互逻辑）
├── assets/
│   ├── svg/            # 手绘插画、图标（可独立文件）
│   └── images/         # 地点图片（第一版用自绘/占位图）
└── README.md           # 本文件
```

## 如何运行与预览

方式一（最简单）：直接双击 `index.html`，用浏览器打开即可。

方式二（推荐，更接近真实部署）：在项目文件夹打开命令行，运行

```
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。

> Windows 打开命令行：在文件夹地址栏输入 `cmd` 回车即可。

## 设计规范（摘要）

- 配色：暖纸色背景 `#F6F1E7` / 墨蓝 `#22314E` / 朱红 `#C03A2B` / 淡金 `#C6A15B` / 浅棕 `#8B7355`
- 字体：标题用宋体（衬线），正文用黑体（无衬线）
- 间距：8px 网格系统
- 地图：手绘风格 SVG，地点与道路符合真实地理关系
